# Aerial Survey Manager v2.1.0-rc.7 업데이트 안내

> 릴리스 후보일: 2026-07-23
>
> 상태: `v2.1.0-rc.6`의 오류 안내를 더 쉽게 식별하도록 개선한 후보입니다.
> 사용자 승인 전 정식 `v2.1.0`으로 사용하지 않습니다.

## 이번 후보에서 달라진 점

- 프로젝트 오류 카드에서 사용자 설명 위에 작은 오류 코드 라벨을 표시합니다.
- 정상 취소, 취소 실패, 일반 실패는 전체 오류 분류가 아니라 화면 시나리오로
  구분했습니다.
- 전체 오류는 작업 상태, 6개 오류 영역, 45개 세부 코드, 개별 오류 참조번호의
  계층으로 관리합니다.
- 실제 경로, 스택 트레이스와 외부 프로그램 원문은 계속 사용자에게 숨깁니다.

## 화면 표시 예시

```text
[오류]
[오류 코드: PROCESSING_STEP_FAILED]

처리 단계가 완료되지 않았습니다.
입력 데이터와 오류 참조번호를 확인한 뒤 다시 처리해주세요.

오류 참조번호: ERR-20260723-XXXXXXXXXXXX
```

## 자동 검증 항목

- 프론트엔드 lint
- production build
- 앱 라우팅 검사
- 버전 일치 검사
- 오류 코드가 없는 이전 오류 응답의 화면 호환성
