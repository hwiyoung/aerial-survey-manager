# Aerial Survey Manager v2.1.0-rc.3 업데이트 안내

> 릴리스 후보일: 2026-07-22
>
> 상태: `v2.1.0-rc.2` 검증 중 확인된 EO 썸네일 지연 수정 후보. 승인 전 정식 `v2.1.0`으로 사용하지 않습니다.

## 이번 후보에서 달라진 점

- 프로젝트 업로드 2단계에서 대형 비압축 TIFF의 EO 원본 썸네일이 오래 걸리던
  문제를 개선했습니다.
- 단일 스트립 비압축 RGB TIFF는 전체 원본 대신 필요한 행과 열만 제한적으로
  읽습니다. 지원하지 않는 형식은 기존 GDAL/Pillow 경로를 그대로 사용합니다.
- 같은 지점을 연속 클릭하거나 동일 썸네일 요청이 겹쳐도 한 번만 생성하고
  완성된 캐시를 함께 사용합니다.
- 미리보기 생성 중에는 대형 원본의 최초 생성에 몇 초가 걸릴 수 있음을
  표시합니다.
- 카메라 모델 선택 화면의 “기본 제공 IO 모델 수정은 원본 백업 후 io.csv와
  카메라 목록에 함께 반영됩니다.” 문구를 제거했습니다.

## 운영 검증 체크리스트

- 18120 검증 화면에서 업로드 2단계로 이동해 EO 파일을 불러오기
- 지도 점을 클릭한 뒤 생성 안내와 큰 원본 썸네일이 차례로 표시되는지 확인
- 같은 점을 닫았다 다시 열 때 캐시된 썸네일이 즉시 표시되는지 확인
- 다른 점을 연속으로 클릭해도 팝업과 지도가 정상 반응하는지 확인
- 업로드 3단계 카메라 선택 화면에서 제거 대상 문구가 보이지 않는지 확인
- `/health`, `version.json`과 화면 버전이 모두 `2.1.0-rc.3`인지 확인

## 자동 검증 결과

- 실제 1.36GB, 14,000×34,800 비압축 RGB TIFF 최초 생성 약 3.4초
- 백엔드 테스트 114개 통과
- 프론트엔드 lint, production build, 라우팅 검사 통과

## 기존 후보 기능

넓어진 EO 검토 화면, EO 전체 정보 팝업, 카메라 IO 수정과 삭제 조건 안내는
`v2.1.0-rc.2`와 동일하게 포함됩니다. 처리 취소, 사용자 안전 오류, 로그 보존,
프로젝트 URL 재진입과 단일 union 도엽 클립도 유지됩니다.
