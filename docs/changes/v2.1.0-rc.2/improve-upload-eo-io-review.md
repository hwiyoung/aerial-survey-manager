- 컨테이너 재빌드: `필요 - frontend, api`

## 업데이트 내용

EO 단계의 전체 폭과 표·지도 영역을 넓히고, 점 팝업에서 큰 원본 미리보기와
X·Y·Z·Omega·Phi·Kappa, 원본 CRS와 변환 좌표를 함께 확인할 수 있습니다.
카메라 선택 단계에서는 기본 제공 모델과 직접 추가한 모델 모두 같은 입력 폼으로
수정하며, 삭제 가능 조건은 버튼 툴팁으로 안내합니다.

## 변경 전

EO 팝업이 작고 일부 위치 정보만 표시했으며, 기본 제공 IO 수정은 CSV 원문
편집기를 사용했습니다. 삭제 버튼의 비활성화 조건도 화면에서 확인하기 어려웠습니다.

## 변경 후

EO 팝업은 640px 미리보기와 전체 EO 값을 표시합니다. 기본 제공 IO 모델은 선택한
카메라 블록만 구조화된 폼으로 수정하고, 직접 추가한 모델만 삭제할 수 있다는
내용을 툴팁으로 표시합니다.

## 운영자 참고사항

기본 제공 IO 수정 시 기존과 동일하게 `io.csv`를 백업하고 재파싱 및 DB 동기화에
실패하면 직전 파일을 복원합니다.

## 검증 내용

- 카메라 블록 단위 수정 및 다른 블록·알 수 없는 CSV 필드 보존
- 모델명 변경 시 업체명이 중복으로 붙지 않는지 확인
- 프론트 lint, production build, 화면 이동 검사
- 백엔드 전체 단위 테스트

## 알려진 제한

기본 제공 IO의 물리 센서 크기는 이미지 픽셀 크기와 Pixel Size로 계산됩니다.
