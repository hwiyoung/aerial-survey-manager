## 업데이트 내용

대기 중인 작업은 대기열 메시지를 제거한 뒤 취소하고, 실행 중인 작업만 프로세스
종료 신호를 사용합니다. 두 상태 모두 DB, 상태 파일과 WebSocket이 같은 취소
상태를 반환하는 통합 테스트를 추가했습니다.

프론트 빌드에는 `VERSION` 기반 `version.json`을 포함합니다. HTML과 버전 파일은
캐시하지 않고 해시가 붙은 정적 자산만 장기 캐시합니다. 소스 설치는 프론트를
캐시 없이 먼저 빌드하며, 배포 후 `scripts/check-deployed-version.sh`로 API와
프론트 버전 및 응답 캐시 정책을 함께 확인할 수 있습니다.
