# 프로젝트 화면 URL과 재진입 상태 통합

- 대상 버전: `v2.1.0`
- 분류: `버그 수정`
- 영역: `프론트 | 화면 이동`
- 사용자 영향: `있음`
- DB 마이그레이션: `없음`
- 환경변수·설정 변경: `없음`
- 컨테이너 재빌드: `필요 - frontend`
- 기존 데이터 영향: `없음`

## 업데이트 내용

처리 화면 열기와 나가기를 공통 URL 상태 함수로 통합했습니다. 로고, 처리 화면
닫기, 프로젝트 생성 실패로 대시보드에 돌아갈 때 `projectId`, `viewMode`와
프로젝트·이미지·도엽 선택 상태를 함께 지웁니다.

`viewMode=processing&projectId=...` 형식의 유효한 직접 링크는 새로고침과 브라우저
앞/뒤 이동에서 복원합니다. 쿼리가 불완전하거나 프로젝트가 삭제되었거나 현재
계정에서 접근할 수 없으면 URL을 대시보드 주소로 정리합니다.
