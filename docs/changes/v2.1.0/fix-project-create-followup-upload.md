# 프로젝트 생성 직후 업로드 안정화

- 대상 버전: `v2.1.0`
- 분류: `버그 수정`
- 영역: `프로젝트 | 업로드`
- 사용자 영향: `있음`
- DB 마이그레이션: `없음`
- 환경변수·설정 변경: `없음`
- 컨테이너 재빌드: `필요 - api`
- 기존 데이터 영향: `없음`

## 업데이트 내용

프로젝트를 만든 직후 이어지는 EO 업로드나 로컬 이미지 등록 요청이 새
프로젝트를 안정적으로 찾을 수 있도록 생성 트랜잭션을 응답 전에 확정합니다.

## 변경 전

프로젝트 생성 응답이 먼저 전송되고 요청 단위 DB 정리가 뒤늦게 실행되면,
바로 이어진 업로드 요청이 아직 확정되지 않은 프로젝트를 찾지 못해 등록을
실패할 수 있었습니다.

## 변경 후

프로젝트 생성 API가 응답을 만들기 전에 DB 커밋을 완료합니다. 생성 직후
시작되는 후속 업로드 요청에서도 프로젝트가 일관되게 조회됩니다.

## 운영자 참고사항

DB 스키마와 환경변수 변경은 없습니다. API 이미지만 새 버전으로
재빌드·교체하면 됩니다.

## 검증 내용

- 프로젝트 추가, ID 할당, 커밋, 응답 생성 순서 회귀 테스트
- 현재 FastAPI 요청 수명주기에서 명시적 커밋 동작 확인
