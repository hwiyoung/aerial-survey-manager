# 단일 union 도엽 클립 내보내기

- 대상 버전: `v2.1.0`
- 분류: `기능 개선`
- 영역: `내보내기 | 지도 | 도엽`
- 사용자 영향: `있음`
- DB 마이그레이션: `있음 - clip_export_jobs 이력 테이블 추가`
- 환경변수·설정 변경: `없음 - 결과 기본 7일 보존`
- 컨테이너 재빌드: `필요 - frontend, api, celery-worker`
- 기존 데이터 영향: `없음 - 신규 클립 결과와 이력만 생성`

## 업데이트 내용

- 내보내기 창 상단에 유형, 좌표계, 해상도, 이름을 배치하고 그 아래에서 COG와 도엽을 함께 확인한다.
- 여러 도엽과 여러 프로젝트를 선택해도 도엽별 파일을 만들지 않고 선택 도엽 MultiPolygon을 cutline으로 사용한 결과 파일 하나를 만든다.
- 파일명은 `{기본이름}_clip.ext`로 통일하며 도엽번호는 파일명 대신 `clip_export_jobs.sheet_ids` 이력에 저장한다.
- 실제 COG 레이아웃, 지리참조, 밴드를 확인한 뒤 일반 Celery 큐에서 비동기로 클립하고 실제 진행률, 단계, 취소, 안전 오류 참조번호를 기록한다.
- 생성 결과는 7일간 보존하며 최근 이력에서 도엽번호와 결과 다운로드 가능 여부를 확인할 수 있다.
- 현재 배포 GDAL에 ECW 드라이버가 없어 내보내기 창에서는 ECW 선택을 비활성화한다.
