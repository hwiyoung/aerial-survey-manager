# EO 원본 썸네일 최초 표시 개선

- 대상 버전: `v2.1.0`
- 분류: `성능 개선`
- 영역: `업로드`
- 사용자 영향: `있음`
- DB 마이그레이션: `없음`
- 환경변수·설정 변경: `없음`
- 컨테이너 재빌드: `필요 - API, 프론트엔드`
- 기존 데이터 영향: `없음`

## 업데이트 내용

프로젝트 업로드 2단계 EO 위치 팝업에서 대용량 원본 TIFF의 썸네일이
멈춘 것처럼 보이던 문제를 개선했습니다. 같은 썸네일을 동시에 요청해도 한 번만
생성하며, 생성 중에는 최초 생성 지연 안내를 표시합니다.

## 변경 전

단일 스트립으로 저장된 1GB 이상 비압축 항공 TIFF는 작은 썸네일을 만들 때도
원본 전체를 읽어야 해서 팝업 이미지가 표시되기까지 오래 걸릴 수 있었습니다.

## 변경 후

지원되는 비압축 RGB TIFF는 필요한 행과 열만 제한적으로 샘플링해 미리보기를
생성합니다. 지원하지 않는 TIFF·JPEG·PNG는 기존 GDAL/Pillow 경로를 유지합니다.
카메라 모델 선택 화면의 중복 IO 저장 안내 문구도 제거했습니다.

## 운영자 참고사항

API와 프론트엔드 이미지를 다시 빌드해야 합니다. DB·환경변수·기존 원본 파일은
변경하지 않습니다.

## 검증 내용

- 실제 1.36GB, 14,000×34,800 비압축 RGB TIFF에서 최초 생성 약 3.4초 확인
- 동일 썸네일 동시 요청 시 한 번만 생성되는 단위 테스트 추가
- 지원 TIFF 빠른 경로와 기존 형식 fallback 단위 테스트 통과
- 전체 백엔드 114개 테스트, 프론트 lint·build·라우팅 검사 통과

## 알려진 제한

압축 TIFF나 특수 색상·타일 구조는 호환성을 위해 기존 생성 경로를 사용하므로
원본 구조와 디스크 상태에 따라 최초 생성 시간이 더 걸릴 수 있습니다.
