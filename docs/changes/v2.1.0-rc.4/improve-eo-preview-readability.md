## 업데이트 내용

프로젝트 업로드 2단계의 EO 점 팝업에서 세로 원본도 실제 비율로 더 크게
확인할 수 있습니다. 미리보기를 클릭하면 전체 화면에서 최대 4배 확대하고
드래그해 이동할 수 있습니다.

## 변경 전

세로 원본은 어두운 빈 공간의 비중이 커서 피사체가 작게 보였고, EO 위치와
자세 값은 두 열에 세 줄로 나뉘었습니다. 지도 표시용 변환 좌표도 WGS84라는
이름으로 노출되어 원본 EO 정보와 혼동할 수 있었습니다.

## 변경 후

실제 비율의 전체 이미지를 흐린 배경 위에 표시해 여백의 대비를 줄이고,
클릭 확대 뷰어에 버튼·휠 확대, 드래그 이동, 보기 초기화를 제공합니다. X·Y·Z는
한 줄, Omega·Phi·Kappa는 한 줄로 정리하고 WGS84 변환 좌표 표시는 숨깁니다.
지도 렌더링을 위한 내부 좌표 변환은 그대로 유지합니다.

## 운영자 참고사항

프론트엔드 이미지를 재빌드해야 합니다. DB, 원본 EO 파일과 기존 썸네일
캐시는 변경하지 않습니다.

## 검증 내용

- 프론트엔드 lint 통과
- production build 통과
- 앱 라우팅 검사 통과
- 실제 640×996 세로 미리보기의 원본 비율 유지와 팝업 전체 내용 표시 확인
- 전체 화면 150% 확대, 드래그 이동, 보기 초기화와 닫기 동작 확인
- EO 위치·자세 한 줄 배치와 팝업 내 WGS84 변환 좌표 숨김 확인

## 알려진 제한

확대 화면의 선명도는 서버가 생성한 미리보기 해상도 범위 안에서 제공됩니다.
