## 업데이트 내용

사용자나 운영자가 무엇을 할 수 있게 되었는지, 어떤 문제가 해결되는지
1~3문장으로 설명합니다.

## 변경 전

기존 동작, 불편, 제한 또는 오류 조건을 설명합니다.

## 변경 후

새 동작과 사용자가 확인할 수 있는 결과를 설명합니다.

## 운영자 참고사항

배포, 재빌드, 환경변수, DB 마이그레이션, 데이터 백업, 롤백 관련 사항을
작성합니다. 별도 작업이 없다면 `별도 운영 작업 없음`이라고 적습니다.

## 검증 내용

- 검증한 정상 동작
- 확인한 오류·경계 조건
- 수행한 회귀 테스트
