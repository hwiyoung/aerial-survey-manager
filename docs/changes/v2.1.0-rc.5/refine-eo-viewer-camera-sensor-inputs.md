## 업데이트 내용

EO 확대창에서 화면 맞춤·너비 맞춤·원본 1:1을 선택하고 넘치는 이미지를
드래그해 확인할 수 있습니다. 카메라 모델의 물리 센서 크기는 센서 해상도와
Pixel Size를 기준으로 자동 계산합니다.

## 변경 전

확대창의 100%가 화면 맞춤 배율인지 원본 픽셀 크기인지 구분하기 어려웠습니다.
카메라 모델은 기본 제공 모델만 센서 mm가 잠기고 직접 추가 모델은 독립 입력할
수 있어 화면 표시값과 처리 입력값이 달라질 수 있었습니다.

## 변경 후

보기 방식 이름을 명시하고 각 방식에서 확대·드래그·초기화를 지원합니다.
기본 제공 모델과 직접 추가 모델 모두 물리 센서 크기를
`센서 해상도(px) × Pixel Size(µm) ÷ 1000`으로 계산해 API 저장값과 처리 엔진
입력 기준을 일치시킵니다.
