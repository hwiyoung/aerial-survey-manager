# 표준 카메라 IO 영속 관리

- 대상 버전: `v2.1.0-rc.1`
- 분류: `기능 개선`
- 영역: `카메라 | IO | 운영 설정`
- 사용자 영향: `있음`
- DB 마이그레이션: `없음`
- 환경변수·설정 변경: `선택 - CONFIG_DATA_PATH, CAMERA_IO_BACKUP_COUNT`
- 컨테이너 재빌드: `필요 - frontend, api`
- 기존 데이터 영향: `최초 실행 시 패키지 io.csv를 영속 설정 경로로 복사`

## 업데이트 내용

카메라 선택 단계에서 현재 운영 계정이 표준 `io.csv` 원문을 관리할 수 있습니다.
패키지의 읽기 전용 `/app/data/io.csv`는 초기 원본으로만 사용하며, 실제 운영본은
`/data/config/io.csv`에 보존합니다.

저장은 기존 SHA-256 확인, CP949/UTF-8 재인코딩 가능 여부, 카메라 블록과 필수
수치 검증을 먼저 수행합니다. 검증 후 이전 파일을 `backups/`에 보존하고 같은
디렉터리의 임시 파일을 `fsync`한 뒤 원자적으로 교체합니다. 이어서 표준 카메라
DB를 동기화하며, DB 반영 실패 시 파일을 직전 내용으로 자동 복원합니다. 백업은
기본 최근 20개를 유지합니다.
