# Aerial Survey Manager v2.1.0 업데이트 안내

> 배포일: 2026-07-23
>
> 상태: 정식 릴리즈

## 핵심 업데이트

이번 업데이트는 `v2.0.1` 이후 추가한 도엽 클립 내보내기, 표준 카메라 IO
관리, EO 원본 검토와 사용자 안전 오류 안내를 정식 기능으로 제공합니다.
RC.1부터 RC.7까지의 자동·현장 검증과 `develop` 통합 회귀 검사를 반영했습니다.

## 신규 기능

### 단일 union 도엽 클립 내보내기

- 여러 프로젝트와 최대 50개 도엽을 선택해 결과 파일 하나로 만듭니다.
- 유형, 좌표계, 해상도와 기본 파일명을 내보내기 창에서 지정합니다.
- 선택 도엽은 MultiPolygon cutline으로 처리하고 도엽번호는 최근 이력에
  보존합니다.
- COG 검증, 실제 진행 단계, 취소, 오류 안내와 완료 후 자동 다운로드를
  제공합니다.
- 완료 결과는 `{권역}_{프로젝트}_ortho_clip.ext` 이름으로 정사영상 루트에
  보관하고, 이름이 겹치면 `(1)`, `(2)`를 붙여 기존 파일을 보호합니다.
- 최근 이력에서 다시 다운로드하거나 서버 결과 파일만 삭제할 수 있습니다.

### 표준 카메라 IO 관리

- 운영 중인 표준 `io.csv`를 웹 입력 폼에서 수정합니다.
- 저장 전 형식과 숫자를 검증하고 원본을 백업한 뒤 원자적으로 교체합니다.
- DB 동기화 실패 시 직전 파일을 자동 복원합니다.
- 센서 크기는 센서 해상도와 Pixel Size를 기준으로 일관되게 계산합니다.

### EO 원본 검토

- 프로젝트 생성 전 EO 점을 열 때만 원본 미리보기를 지연 생성합니다.
- 세로·가로 이미지의 실제 비율을 유지합니다.
- 전체 화면에서 화면 맞춤, 너비 맞춤과 원본 1:1 보기를 전환하고 확대·이동할
  수 있습니다.
- 대형 비압축 RGB TIFF는 필요한 행·열만 제한적으로 읽고, 같은 원본의 동시
  요청은 하나의 캐시를 공유합니다.

## 기능 개선

### 사용자 안전 오류와 취소 상태

- 경로, 스택과 외부 프로그램 원문 대신 오류 코드, 사용자 설명, 조치 방법과
  참조번호를 표시합니다.
- 정상 취소는 오류와 분리하고 다시 시작 안내만 제공합니다.
- 프로젝트별 처리 로그를 순환하고 오류 참조번호별 진단 묶음을 제한된 기간과
  용량 안에서 보존합니다.

### 화면 이동과 프런트 최신화

- 프로젝트 화면 종료 시 URL과 선택 상태를 함께 정리합니다.
- 유효한 직접 링크, 새로고침과 브라우저 앞·뒤 이동은 해당 화면을 복원합니다.
- HTML과 `version.json`은 캐시하지 않고 해시가 있는 정적 자산만 장기
  캐시합니다.

## 오류 수정

- 프로젝트 생성 응답 전에 DB 커밋을 완료해 생성 직후 EO 업로드와 로컬 이미지
  등록이 간헐적으로 실패하던 문제를 수정했습니다.
- 긴 한글 권역·프로젝트명이 파일시스템 한도를 넘지 않도록 클립 파일명을
  UTF-8 바이트 기준으로 안전하게 줄입니다.
- 클립 작업 임시 폴더와 완료 결과의 보존 정책을 분리했습니다.
- 워커 종료 예외가 정상 취소 상태를 처리 실패로 덮어쓰지 않도록 했습니다.
- 대형 EO 원본의 최초 미리보기가 멈춘 것처럼 보이던 지연을 줄였습니다.

## 운영자 안내

| 항목 | 내용 |
|---|---|
| 컨테이너 재빌드 | 전체 패키지 교체 권장 |
| DB 마이그레이션 | 있음 — 오류 메타데이터와 `clip_export_jobs` 이력 테이블, API 시작 시 Alembic 자동 적용 |
| 환경변수 | 필수 신규 값 없음, 로그·IO 보존 설정은 기본값 제공 |
| 데이터 영향 | 기존 프로젝트·정사영상은 유지, 새 클립 결과는 `EXPORT_ROOT_PATH` 루트에 보관 |
| 호환성 | 기존 API·설정과 호환, `v2.0.1`에서 직접 업그레이드 가능 |
| 롤백 | 업그레이드 전 DB와 `EXPORT_ROOT_PATH`, 설정 파일을 백업하고 스키마 적용 후에는 백업 복원 기준으로 롤백 |

기존 `clip-jobs/` 결과는 자동으로 루트로 이동하지 않습니다. 새 완료 결과는
최근 이력에서 삭제하거나 운영자가 정리할 때까지 유지하며, 7일 정책은 비정상
종료로 남은 임시 작업 폴더에만 적용됩니다.

## 알려진 제한

- 배포 GDAL에 ECW 드라이버가 없어 ECW 내보내기는 비활성화되어 있습니다.
- 여러 프로젝트를 한 번에 클립하면 권역을 하나로 확정하지 않고
  `bulk_export_clip` 기본 이름을 사용합니다.

## 업데이트 확인

```bash
cat VERSION
curl -fsS http://127.0.0.1:18100/health
curl -fsS http://127.0.0.1:18100/version.json
```

세 응답의 버전이 모두 `2.1.0`이어야 합니다.
