## v2.1.0-rc.3 (2026-07-22)

> `v2.1.0-rc.2` 현장 검증 중 확인된 EO 원본 미리보기 지연을 수정한 세 번째
> 릴리스 후보입니다.

| # | 항목 | 내용 |
|---|------|------|
| PERFORMANCE | 대형 EO 원본 미리보기 | 단일 스트립 비압축 RGB TIFF를 제한 샘플링해 실제 1.36GB 검증 파일의 최초 썸네일 생성을 약 3.4초로 단축 |
| RELIABILITY | 썸네일 중복 생성 방지 | 같은 원본의 동시 요청을 직렬화해 한 장을 중복 생성하지 않고 완성된 캐시를 재사용 |
| UX | 생성 상태·카메라 안내 정리 | 대형 원본의 최초 생성 지연을 안내하고 카메라 선택 화면의 중복 IO 저장 안내 문구 제거 |

| # | 항목 | 내용 |
|---|------|------|

| FIX | 프로젝트 URL 재진입 | 명시적 나가기는 URL·선택 상태를 정리하고 유효한 직접 링크·새로고침은 프로젝트 화면을 복원 |
