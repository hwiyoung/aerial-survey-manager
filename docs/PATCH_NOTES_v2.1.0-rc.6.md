# Aerial Survey Manager v2.1.0-rc.6 업데이트 안내

> 릴리스 후보일: 2026-07-23
>
> 상태: `v2.1.0-rc.5` 검증 중 확인된 처리 취소 표시를 수정한 후보입니다.
> 사용자 승인 전 정식 `v2.1.0`으로 사용하지 않습니다.

## 이번 후보에서 달라진 점

- 정상적인 처리 취소를 처리 오류와 분리했습니다.
- 취소 요청은 취소 상태를 DB에 먼저 저장한 뒤 워커 종료 신호를 보냅니다.
- 정상 취소 프로젝트에는 회색 안내와 다시 시작 방법만 표시합니다.
- 정상 취소에는 오류 코드와 오류 참조번호를 표시하지 않습니다.
- 취소 상태를 DB에 저장하지 못한 경우에만 전용 취소 실패 오류를 표시합니다.
- 현재 45개 공개 오류 코드를 정상 상태와 분리해 운영 관점의 6개 묶음으로
  정리했습니다.

## 화면 표시 기준

| 상황 | 상태 배지 | 안내 | 오류 참조번호 |
|---|---|---|---|
| 정상 취소 | 취소 | 처리가 취소되었으며 다시 시작할 수 있음 | 없음 |
| 취소 상태 저장 실패 | 오류 | 상태를 새로고침한 뒤 다시 취소 | 있음 |
| 실제 처리 실패 | 오류 | 분류된 오류 설명과 조치 | 있음 |

## 운영 검증 체크리스트

- 대기 중인 작업 취소 후 `취소` 배지와 회색 안내가 표시되는지 확인
- 실행 중인 작업 취소 후 처리 실패 오류로 바뀌지 않는지 확인
- 취소된 프로젝트에서 오류 참조번호가 표시되지 않는지 확인
- 취소된 프로젝트를 다시 처리할 수 있는지 확인
- 실제 처리 실패 프로젝트에는 오류 설명·조치·참조번호가 유지되는지 확인

## 자동 검증 결과

- 프론트엔드 lint, production build, 앱 라우팅 검사 통과
- 백엔드 전체 테스트 117개 통과
- 취소 상태 저장이 워커 종료 신호보다 먼저 수행되는 순서 검증 통과
- 워커 제어 채널 오류가 정상 취소를 처리 실패로 바꾸지 않는 회귀 테스트 통과
- 취소 상태 저장 실패가 `PROCESSING_CANCEL_FAILED`로 분류되는 테스트 통과

## 알려진 검증 범위

실제 대기·실행 Celery 작업을 사용한 18120 현장 취소 검증은 배포 후 수행합니다.
