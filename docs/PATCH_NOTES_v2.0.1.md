# Aerial Survey Manager v2.0.1 업데이트 안내

> 릴리스일: 2026-07-22
>
> 상태: 정식 버그 수정 릴리스

## 핵심 업데이트

`v2.0.0` 이후 정사영상 최종 저장 경로를 평면 구조로 복원하고, 같은 이름의
기존 파일을 안전하게 보호하도록 수정했습니다. 새 사용자 기능은 포함하지
않습니다.

## 정사영상 경로와 덮어쓰기

- 최종 정사영상은 `EXPORT_ROOT_PATH/{권역}_{프로젝트명}.tif` 형식으로
  저장합니다.
- 같은 프로젝트를 재처리하면 완성된 새 COG가 기존 결과를 원자적으로
  교체합니다.
- 다른 프로젝트나 DB에 등록되지 않은 파일과 이름이 겹치면 기존 파일을
  덮어쓰지 않고 `(1)`, `(2)` 번호를 붙입니다.
- 최종 COG 발행을 워커 한 곳으로 통합해 중복 파일 생성을 방지합니다.

## 기존 데이터 변환

`v2.0.0-rc.1`에서 생성된 UUID 하위 폴더 결과가 있다면 DB와
`EXPORT_ROOT_PATH`를 백업한 뒤 먼저 dry-run을 실행합니다.

```bash
./scripts/migrate-orthomosaic-layout.sh
```

파일 매핑과 자동 번호가 맞고 누락·추가 파일 경고가 없을 때만 적용합니다.

```bash
./scripts/migrate-orthomosaic-layout.sh --apply
```

수동으로 파일만 이동하면 DB 경로와 달라질 수 있으므로 사용하지 않습니다.

## 검증 체크리스트

- 신규 처리 결과가 평면 최종 경로에 저장되는지 확인
- 같은 프로젝트 재처리 시 최종 파일이 정상 교체되는지 확인
- 다른 프로젝트와 이름이 겹칠 때 `(1)`, `(2)`가 붙는지 확인
- 마이그레이션 dry-run 결과와 DB 프로젝트 매핑 확인

## 알려진 제한

- 경로 변환 도구는 로컬 스토리지 배포만 지원합니다.
- 현재 DB가 가리키지 않는 과거 결과 파일은 자동으로 옮기지 않습니다.
