# Aerial Survey Manager v2.1.0-rc.1 업데이트 안내

> 릴리스 후보일: 2026-07-22
>
> 상태: 운영 검증 후보. 승인 전 정식 `v2.1.0`으로 사용하지 않습니다.

## 핵심 업데이트

이번 후보는 `v2.0.1`을 기준으로 처리 취소와 화면 상태를 보완하고, 안전한 오류
안내, 로그 보존, 표준 카메라 IO 관리, EO 원본 미리보기와 새 도엽 클립
내보내기를 추가합니다. 역할이나 조직별 화면을 새로 나누지 않으며 현재 운영
계정에서 같은 기능을 사용합니다.

## 사용자 화면

- 오류 화면은 기술 예외 원문 대신 오류 코드, 사용자용 설명, 조치 방법과
  오류 참조번호를 표시합니다. 경로, 스택트레이스와 GDAL 원문은 숨깁니다.
- 프로젝트 화면에서 명시적으로 나가면 `projectId`, `viewMode`와 선택 상태를
  지웁니다. 유효한 직접 링크의 새로고침과 브라우저 앞·뒤 이동은 해당 화면을
  다시 엽니다.
- 프로젝트 생성 전 EO 지도에서 점 팝업을 열면 원본 이미지의 작은
  미리보기를 그때 생성합니다. 점 클릭 자체는 처리 제외 상태를 바꾸지 않습니다.
- 카메라 선택 단계에서 영속 표준 `io.csv`를 편집하고 검증·저장할 수 있습니다.

## 내보내기와 도엽 클립

- 내보내기 창 상단에 유형, 좌표계, 해상도와 이름을 배치하고 아래 지도에 실제
  COG와 도엽을 함께 표시합니다.
- 선택한 여러 도엽과 프로젝트를 MultiPolygon cutline으로 모자이크·클립해
  결과 파일 하나를 만듭니다.
- 클립 파일명은 `{기본이름}_clip.ext`입니다. 선택 도엽번호는 파일명이 아니라
  최근 클립 이력에 모두 보존합니다.
- 대용량 작업은 Celery에서 비동기로 실행하며 단계·진행률·취소와 안전한 오류
  참조번호를 표시합니다. 완료 결과는 기본 7일 동안 다시 받을 수 있습니다.
- GeoTIFF 결과는 COG로 생성하고 검증합니다. JPG와 PNG를 지원하며 배포 GDAL에
  드라이버가 없는 ECW는 비활성화합니다.

## 처리와 운영 안정성

- 대기 작업은 대기열에서 취소하고 실행 작업만 종료하도록 상태별 취소 동작을
  통합 검증합니다.
- HTML과 `version.json`은 캐시하지 않고 해시 정적 자산만 장기 캐시합니다.
- 프로젝트별 처리 로그는 50MB 단위, 백업 3개로 순환합니다.
- 오류 발생 시 최근 로그·상태·manifest를 오류 참조번호별 진단 묶음으로
  보존합니다. 기본 정책은 30일, 프로젝트당 20개, 전체 20GB입니다.

## 데이터와 마이그레이션

업데이트 시작 전에 DB와 `EXPORT_ROOT_PATH`, 설정 경로를 백업합니다.

| 항목 | 영향 |
|---|---|
| DB | `processing_jobs` 오류 코드·참조번호와 `clip_export_jobs` 이력 테이블 추가 |
| 표준 IO | 패키지 원본을 최초 1회 `/data/config/io.csv`로 복사하고 이후 영속 관리 |
| EO 미리보기 | `/data/config/image-previews`에 7일 또는 전체 1GB 한도의 캐시 생성 |
| 클립 결과 | `/data/exports/clip-jobs`에 생성하고 기본 7일 보존 |

`v2.0.0`에서 바로 올라오는 설치는 먼저 `v2.0.1`의 정사영상 경로 변환
dry-run 지침을 확인합니다.

## 운영 검증 체크리스트

- 대기 상태와 실행 상태에서 각각 처리 취소
- 오류 화면에 경로·스택·GDAL 원문이 보이지 않고 참조번호가 표시되는지 확인
- 프로젝트 처리 로그 순환과 오류 진단 묶음 생성 확인
- 표준 `io.csv` 수정, 백업, 재시작 후 유지와 DB 모델 동기화 확인
- 프로젝트 생성 전 EO 점에서 가로·세로 원본 미리보기 확인
- 유효한 프로젝트 URL 새로고침 재진입과 명시적 나가기 URL 정리 확인
- 실제 COG 위에서 여러 도엽 선택 후 결과가 하나이고 이름에 `_clip`이 붙는지 확인
- 최근 클립 이력에 선택한 모든 도엽번호와 완료·오류 상태가 남는지 확인
- `VERSION`, `/health`, `version.json`이 모두 `2.1.0-rc.1`인지 확인

## 알려진 제한

- ECW 내보내기는 배포 GDAL에 ECW 드라이버가 없어 비활성화되어 있습니다.
- 클립은 한 작업에서 최대 50개 도엽과 20개 프로젝트를 처리합니다.
