# Aerial Survey Manager v2.1.0-rc.2 업데이트 안내

> 릴리스 후보일: 2026-07-22
>
> 상태: `v2.1.0-rc.1` 검증 의견 반영 후보. 승인 전 정식 `v2.1.0`으로 사용하지 않습니다.

## 이번 후보에서 달라진 점

- 프로젝트 업로드 2단계 창을 최대 1600px·화면 폭 98%까지 넓혔습니다.
- EO 행 표와 위치 지도의 높이를 키워 더 많은 데이터를 한 화면에서 확인합니다.
- EO 점 팝업은 640px 원본 미리보기와 X·Y·Z·Omega·Phi·Kappa, 원본 CRS,
  변환된 WGS84 좌표를 모두 표시합니다.
- 카메라 선택 화면에서 ‘표준’과 ‘IO 관리’ 표현을 제거하고 모든 모델에
  **수정** 버튼과 동일한 구조의 입력 폼을 사용합니다.
- 기본 제공 IO 모델은 선택한 `io.csv` 카메라 블록만 수정하며, 기존 원본 백업,
  재파싱 검증, 원자적 저장과 DB 동기화·실패 시 복원을 유지합니다.
- 삭제 버튼 툴팁에서 직접 추가한 모델만 삭제할 수 있음을 안내합니다. 사용 중인
  추가 모델을 삭제하면 기존 이미지와의 카메라 연결은 해제됩니다.

## 운영 검증 체크리스트

- 넓어진 EO 단계에서 표와 지도가 가로로 잘리지 않는지 확인
- EO 점 클릭 후 큰 썸네일과 EO 6개 값, CRS·변환 좌표가 모두 보이는지 확인
- 기본 제공 IO 모델의 수정 화면이 추가 화면과 같은 입력 구조인지 확인
- 기본 제공 IO 수정 후 재접속·재시작해도 값이 유지되는지 확인
- 기본 제공 IO 모델의 삭제 버튼이 비활성이고 툴팁이 표시되는지 확인
- 직접 추가한 모델은 수정·삭제가 가능한지 확인
- `/health`, `version.json`과 화면 버전이 모두 `2.1.0-rc.2`인지 확인

## 기존 후보 기능

처리 취소, 사용자 안전 오류, 로그 보존, 프로젝트 URL 재진입, 단일 union 도엽
클립은 `v2.1.0-rc.1`과 동일하게 포함됩니다.
