# Aerial Survey Manager v2.1.0-rc.4 업데이트 안내

> 릴리스 후보일: 2026-07-22
>
> 상태: `v2.1.0-rc.3` 검증 의견을 반영한 EO 미리보기 UI 개선 후보. 승인 전 정식 `v2.1.0`으로 사용하지 않습니다.

## 이번 후보에서 달라진 점

- 프로젝트 업로드 2단계의 EO 점 팝업 폭과 이미지 영역을 넓혔습니다.
- 세로 이미지 전체를 원본 비율로 유지하면서 같은 이미지의 흐린 채움 배경을
  사용해 좌우 빈 공간의 대비를 줄였습니다.
- 미리보기를 클릭하면 전체 화면으로 열립니다. 버튼이나 마우스 휠로 최대
  4배 확대하고, 확대된 이미지를 드래그해 이동하거나 초기화할 수 있습니다.
- EO 전체 정보는 X·Y·Z를 한 줄, Omega·Phi·Kappa를 한 줄에 표시합니다.
- 지도 점 배치에 필요한 WGS84 변환은 유지하되 팝업의 WGS84 좌표 문구는
  숨겨 원본 EO 좌표와의 혼동을 줄였습니다.

## 운영 검증 체크리스트

- 18120 검증 화면에서 업로드 2단계로 이동해 EO 파일을 불러오기
- 지도 점을 클릭했을 때 세로 원본이 잘리지 않고 더 큰 영역에 표시되는지 확인
- 이미지 클릭 후 전체 화면 뷰어가 열리고 확대·축소·드래그·초기화가 동작하는지 확인
- EO 정보의 위치와 자세가 각각 한 줄로 표시되는지 확인
- 팝업에 WGS84 좌표 문구가 없고 지도 점 위치는 이전과 같은지 확인
- `/health`, `version.json`과 화면 버전이 모두 `2.1.0-rc.4`인지 확인

## 자동 검증 결과

- 프론트엔드 lint 통과
- 프론트엔드 production build 통과
- 앱 라우팅 검사 통과
- 실제 84장 이미지와 1,551행 EO 파일로 640×996 세로 미리보기의 원본 비율,
  팝업 전체 정보 표시와 WGS84 변환 좌표 숨김 확인
- 전체 화면 150% 확대, 드래그 이동, 보기 초기화와 닫기 동작 확인

## 기존 후보 기능

대형 TIFF 빠른 지연 미리보기와 캐시 재사용은 `v2.1.0-rc.3`과 동일하게
유지됩니다. 넓어진 EO 검토 화면, 카메라 IO 수정, 처리 취소, 사용자 안전 오류,
로그 보존, 프로젝트 URL 재진입과 단일 union 도엽 클립도 그대로 포함됩니다.
