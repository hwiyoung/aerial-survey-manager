# Aerial Survey Manager v2.1.0-rc.5 업데이트 안내

> 릴리스 후보일: 2026-07-23
>
> 상태: `v2.1.0-rc.4` 현장 검증 의견을 반영한 EO·카메라 입력 개선 후보. 승인 전 정식 `v2.1.0`으로 사용하지 않습니다.

## 이번 후보에서 달라진 점

- EO 전체 화면 미리보기에 `화면 맞춤`, `너비 맞춤`, `원본 1:1` 보기 방식을
  추가했습니다.
- 너비 맞춤과 원본 1:1에서 화면 밖으로 넘치는 이미지는 확대하지 않은
  상태에서도 드래그해 이동할 수 있습니다.
- 확대 배율 100% 대신 현재 보기 방식의 이름을 표시해 화면 맞춤과 원본
  픽셀 크기를 혼동하지 않도록 했습니다.
- 모든 카메라 모델에서 물리 센서 크기를 센서 해상도와 Pixel Size로 자동
  계산합니다.
- 카메라 입력 항목을 `센서 해상도 W/H (px)`와 `센서 W/H (mm, 자동 계산)`로
  구분하고 계산 기준을 화면에 표시합니다.

## 운영 검증 체크리스트

- EO 점 팝업에서 원본 이미지 전체가 잘리지 않는지 확인
- 전체 화면에서 세 가지 보기 방식과 확대·축소·드래그·초기화 확인
- 카메라 모델 수정에서 Pixel Size나 센서 해상도를 바꿀 때 센서 mm가 즉시
  다시 계산되는지 확인
- 기본 제공 모델 저장 시 `io.csv`와 DB의 센서 계산값이 일치하는지 확인
- 직접 추가 모델도 같은 계산 기준으로 저장되는지 확인
- `/health`, `version.json`과 화면 버전이 모두 `2.1.0-rc.5`인지 확인

## 자동 검증 결과

- 프론트엔드 lint와 production build 통과
- 앱 라우팅 검사 통과
- 백엔드 전체 테스트 115개 통과
- 실제 84장 이미지와 1,551행 EO 파일로 보기 방식 전환과 드래그 확인
- 카메라 수정 폼에서 Pixel Size와 센서 해상도 변경 시 물리 센서 크기 즉시
  재계산 확인

## 기존 후보 기능

EO 팝업의 실제 비율 표시, X·Y·Z와 Omega·Phi·Kappa 두 줄 구성, WGS84 문구
숨김 및 대형 TIFF 지연 미리보기는 이전 후보와 동일하게 유지됩니다.
